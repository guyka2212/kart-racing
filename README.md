# Kart Racing

A free kart racing sim for Windows. Drive with a steering wheel, a controller, keyboard & mouse, or in VR.

**Website:** https://guyka2212.github.io/kart-racing/
**Download:** [KartRacingSetup.exe](https://github.com/guyka2212/kart-racing/releases/latest/download/KartRacingSetup.exe) (Windows 10/11, 64-bit)

- 27 tracks
- Up to 7 opponents, bot levels from Rookie to Alien
- Tyre temperature and wear on all four tyres, pit lane and pit crew
- Wheel calibration for any HID wheel, button mapping for wheel, controller and keyboard
- VR (OpenXR) with an in-helmet view and a data screen on the steering wheel

The installer isn't code-signed yet, so Windows SmartScreen may warn you: click **More info** > **Run anyway**.

This repository holds the website (`index.html`, `img/`) and the installer script (`installer/KartRacing.iss`, built with Inno Setup 6).
